# Johny Burger — site one-page

Next.js + React Three Fiber. Hambúrguer 3D procedural que se monta sozinho ao abrir; nenhuma animação depende de rolagem.

- `npm run dev` / `npm run build` / `npm start`
- Textos e links: `lib/content.ts`
- Pendências do cliente: `PLACEHOLDERS.md`
- Imagens: `node scripts/prepare-images.mjs`
